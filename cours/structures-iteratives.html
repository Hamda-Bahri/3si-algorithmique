Cours d'algorithmique

Les structures de contrôle itératives

Une structure itérative permet de répéter une ou plusieurs instructions. Dans ce cours, nous étudierons les structures Pour, Répéter...Jusqu'à et Tant que, ainsi que les critères permettant de choisir la structure adaptée à une situation.

Sommaire

1. Notion d'itération 2. Pour 3. Répéter...Jusqu'à 4. Tant que 5. Comparaison 6. Choisir la boucle 7. Erreurs fréquentes 8. Vérification 9. Testez-vous

1. Notion d'itération

Une itération correspond à une répétition d'un traitement.

En algorithmique, certaines situations nécessitent d'exécuter plusieurs fois la même instruction ou le même ensemble d'instructions.

Par exemple :

  • afficher les entiers de 1 à 10 ;
  • saisir les notes de 20 élèves ;
  • demander une valeur jusqu'à ce qu'elle soit valide ;
  • traiter successivement les chiffres d'un entier ;
  • chercher un diviseur d'un nombre.
Question essentielle :
Avant de choisir une boucle, demandons-nous : « Connaît-on le nombre d'itérations avant de commencer ? »

2. La structure Pour

La structure Pour est utilisée lorsque le nombre d'itérations est connu à l'avance.

Syntaxe algorithmique

Pour compteur de valeur_initiale à valeur_finale Faire
    Traitement
Fin Pour

Exemple 1 : afficher les entiers de 1 à 5

Algorithme
Pour i de 1 à 5 Faire
    Ecrire(i)
Fin Pour
Python
for i in range(1, 6):
    print(i)
En Python, la borne supérieure de range n'est pas incluse. Ainsi : range(1, 6) produit les valeurs : 1, 2, 3, 4 et 5.

Exemple 2 : calculer la moyenne de N notes

Une fois la valeur de N connue, nous savons exactement combien de notes doivent être saisies. La structure Pour est donc adaptée.

Algorithme
S ← 0

Pour i de 1 à N Faire
    Ecrire("Donner la note ", i)
    Lire(note)
    S ← S + note
Fin Pour

moy ← S / N
Python
s = 0

for i in range(1, n + 1):
    note = float(input("Donner une note : "))
    s = s + note

moy = s / n
À retenir : si le nombre de répétitions est connu avant l'entrée dans la boucle, on privilégie Pour.

3. La structure Répéter...Jusqu'à

La structure Répéter...Jusqu'à est utilisée lorsque le nombre d'itérations n'est pas connu à l'avance et que le traitement doit être effectué avant le test.

Syntaxe

Répéter
    Traitement
Jusqu'à condition
Le traitement est exécuté au moins une fois. La boucle s'arrête lorsque la condition devient vraie.

Exemple : saisie d'une note valide

On veut saisir une note comprise entre 0 et 20. Nous ne savons pas combien de tentatives seront nécessaires. 

Répéter
    Ecrire("Donner une note : ")
    Lire(note)
Jusqu'à note >= 0 et note <= 20

La saisie doit être réalisée une première fois avant de pouvoir vérifier si la note est correcte.

Important : Python ne possède pas directement une instruction Répéter...Jusqu'à. Nous étudions donc cette structure principalement dans la partie algorithmique.

4. La structure Tant que

La structure Tant que est utilisée lorsque le nombre d'itérations n'est pas connu à l'avance et que la condition doit être testée avant le traitement.

Syntaxe

Tant que condition Faire
    Traitement
Fin Tant que
Avec Tant que, la condition est testée avant le traitement. Le traitement peut donc être exécuté zéro fois.

Exemple : déterminer le plus grand facteur premier

Considérons la fonction utilisée pour chercher le plus grand facteur premier d'un entier N > 1.

Python
def PlusGrandFacteur(N):
    f = 2

    while N != 1:
        if N % f == 0:
            N = N // f
        else:
            f = f + 1

    return f

Nous ne savons pas à l'avance combien de divisions ou de changements de la valeur de f seront nécessaires. La structure Tant que est donc adaptée.

5. Différence entre Répéter et Tant que

Structure Moment du test Nombre minimum d'exécutions
Répéter...Jusqu'à Après le traitement 1
Tant que Avant le traitement 0

Exemple

Supposons que x = 15.

Répéter...Jusqu'à
x ← 15

Répéter
    x ← x + 1
Jusqu'à x > 10

Le traitement est effectué avant le test. Ainsi, x devient 16.

Tant que
x ← 15

Tant que x <= 10 Faire
    x ← x + 1
Fin Tant que

La condition est fausse dès le départ. Le traitement n'est jamais exécuté. x reste égal à 15.

Attention aux conditions :
Avec Répéter...Jusqu'à, on exprime généralement la condition d'arrêt. Avec Tant que, on exprime la condition de continuation.

6. Comment choisir la bonne boucle ?

Le choix d'une structure itérative doit être effectué en analysant le problème.

Le nombre d'itérations est-il connu à l'avance ?
↓
OUI → POUR
↓
NON → Faut-il effectuer le traitement avant le test ?
↓
OUI → RÉPÉTER...JUSQU'À     |     NON → TANT QUE
Situation Structure Pourquoi ?
Afficher les entiers de 1 à 20 Pour Le nombre d'itérations est connu.
Saisir 10 notes Pour Exactement 10 saisies.
Saisir un entier strictement positif Répéter Il faut effectuer une première saisie.
Supprimer successivement les chiffres de N Tant que Le nombre d'itérations dépend de N.
Réflexe à acquérir :

Pour : je sais combien de fois je répète.
Répéter...Jusqu'à : je traite d'abord, puis je teste.
Tant que : je teste d'abord, puis je traite.

7. Erreurs fréquentes

Erreur 1 — Créer une boucle infinie

i ← 1

Tant que i <= 10 Faire
    Ecrire(i)
Fin Tant que

La valeur de i ne change jamais. La condition reste donc toujours vraie.

Correction :

i ← 1

Tant que i <= 10 Faire
    Ecrire(i)
    i ← i + 1
Fin Tant que

Erreur 2 — Faire évoluer la variable dans le mauvais sens

i ← 1

Tant que i <= 10 Faire
    Ecrire(i)
    i ← i - 1
Fin Tant que

La valeur devient 1, 0, -1, -2... La condition i <= 10 reste vraie.

Posez-vous la question : « La modification de ma variable me rapproche-t-elle de la condition d'arrêt ? »

Erreur 3 — Mal formuler une condition

Pour accepter une note comprise entre 0 et 20 : 

note >= 0 et note <= 20

et non :

note >= 0 ou note <= 20

Par exemple, pour note = 25, la première proposition est vraie. La condition utilisant ou devient donc vraie alors que la note est incorrecte.

Erreur 4 — Confondre arrêt et continuation

Avec Répéter :

Jusqu'à note >= 0 et note <= 20

Avec Tant que :

Tant que note < 0 ou note > 20 Faire
Ces deux conditions sont opposées. La négation de : note >= 0 et note <= 20 est : note < 0 ou note > 20.

Erreur 5 — Tester une variable non initialisée

Tant que note < 0 ou note > 20 Faire
    Lire(note)
Fin Tant que

Au premier test, note n'a encore reçu aucune valeur.

Une solution correcte est :

Lire(note)

Tant que note < 0 ou note > 20 Faire
    Lire(note)
Fin Tant que

Erreur 6 — Confondre < et <=

Pour afficher les entiers de 1 à 10 : 

Tant que i <= 10 Faire

Si nous utilisons i < 10, la valeur 10 ne sera pas traitée.

Erreur 7 — Modifier manuellement le compteur d'un Pour

Pour i de 1 à 10 Faire
    Ecrire(i)
    i ← i + 1
Fin Pour

Dans une structure Pour, l'évolution du compteur est gérée par la boucle.

Erreur 8 — Utiliser Pour quand le nombre est inconnu

Il ne faut pas choisir arbitrairement un grand nombre d'itérations pour simuler une boucle dont le nombre d'exécutions est inconnu.

Dans ce cas, on étudie plutôt l'utilisation de Tant que ou de Répéter...Jusqu'à.

8. Méthode de vérification

Après avoir écrit une boucle, posez-vous systématiquement les quatre questions suivantes :

1. Pourquoi ai-je choisi cette boucle ? Le nombre d'itérations est-il connu ou inconnu ?

2. Que représente ma condition ? Une condition de continuation ou une condition d'arrêt ?

3. Quelle variable évolue à chaque itération ?

4. Dans quelle situation concrète la boucle s'arrête-t-elle ?

9. Testez-vous

Choisissez la structure qui vous semble la plus adaptée.

Situation 1

On veut afficher les carrés des entiers de 1 à 100.

Situation 2

On veut saisir un âge jusqu'à obtenir une valeur comprise entre 10 et 25.

Situation 3

On dispose déjà d'un entier N et on veut le diviser successivement par 2 tant qu'il est pair.

Situation 4

On veut calculer la somme de 30 nombres saisis.

Situation 5

On veut saisir un mot de passe jusqu'à ce qu'il soit correct.

Activité de réflexion

Choisissez une structure et justifiez mentalement votre réponse :

Situation :
Chercher le premier diviseur d'un entier N à partir de 2 et arrêter la recherche dès qu'un diviseur est trouvé.

Quelle structure choisir ?
Réponse : Tant que.

Le nombre de valeurs à tester n'est pas connu à l'avance. La recherche continue tant que la condition d'arrêt n'est pas atteinte.
